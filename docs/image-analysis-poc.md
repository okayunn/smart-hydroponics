# 植物の緑色領域を計測するPoC

真上から撮影したバジルなどのJPEG/PNG画像1枚を読み、緑色の領域のピクセル数と画像全体に対する割合を計測します。AIは使いません。数値は**画像上の緑色領域の投影面積**であり、実際の葉面積・体積・重量ではありません。

## 環境構築

Python 3.10以上を使用します。Windows PowerShellで、このフォルダーに移動して実行してください。Pythonが未導入の場合はPythonをインストールし、`py`が使える状態にしてください。

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

macOS/Linuxでは次のとおりです。

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

## 実行方法

```powershell
.\.venv\Scripts\python.exe main.py "写真\バジル.jpg" --output-dir "output"
```

画像パスは実在するJPEG/PNGに置き換えてください。macOS/LinuxではPythonのパスを`.venv/bin/python`に置き換えます。日本語や空白を含むパスに対応しています。

標準出力はJSONのみです。例えば次の形式になります（数値は説明用）。

```json
{
  "plant_pixels": 182340,
  "total_pixels": 2073600,
  "plant_coverage_percent": 8.79
}
```

`--output-dir`を省略すると`output`に保存します。

| 出力 | 内容 |
| --- | --- |
| バジル_metrics.json | ピクセル数と割合。割合は小数点以下2桁に丸める |
| バジル_mask.png | 植物と判定した領域が白、それ以外が黒 |
| バジル_overlay.png | 判定領域を半透明のピンクで重ねた確認画像 |

入力画像は変更しません。同名の出力ファイルは再実行で上書きされるため、残したい場合は出力フォルダーを変更してください。エラー時は標準エラー出力に理由を表示し、終了コード1を返します。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| main.py | CLI、画像の読み書き、JSON保存、エラー処理 |
| analysis.py | 緑色領域抽出、面積集計、確認画像生成 |
| requirements.txt | OpenCVとNumPyの依存関係 |
| tests/test_poc.py | 既知面積、境界ケース、CLI・入出力のテスト |
| .gitignore | 仮想環境や出力画像などをGit管理対象から除外 |

## 植物の判定方法

1. OpenCVで画像を8ビットBGRとして読み込む。
2. `analysis.py`の`segment_plant`でHSV（色相・彩度・明度）へ変換。
3. H=35〜85、S=40〜255、V=40〜255の範囲を緑色として抽出する。OpenCVのHは0〜179、S/Vは0〜255で、範囲の端も含む。
4. マスクの非ゼロ画素を数え、`plant_pixels / total_pixels × 100`で割合を計算。
5. 元画像と同じ解像度のマスクと確認画像を保存。

今回は輪郭補完、小領域除去、画像の縮小は行いません。計測値がマスクの白い画素数に直接一致する単純な方式です。将来AIを導入する際は、同じサイズの0/255マスクを返すように`segment_plant`を置き換えれば、集計とCLIを再利用できます。

## 現在の限界・誤検出条件

- 緑色の鉢、背景、支柱、藻、雑草も植物として数える。複数個体は合計される。
- 黄変・茶色化した葉、強い影、白飛び、照明の色かぶりでは葉を見逃す。
- スマートフォンの自動露出・ホワイトバランス、JPEG圧縮で境界の判定が変わる。
- 葉が重なると隠れた部分を測れず、葉の角度や巻きでも値が変わる。
- 撮影距離、画角、解像度、切り抜きが変わると比較できない。割合も画角の影響を受ける。
- PNGの透明度は判定に使わないため、不透明な通常の写真を推奨する。
- 実写真に合わせたしきい値の調整・精度評価はまだ実施していない。

## テスト

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

合成画像で既知の4,000画素/20,000画素=20%を確認し、植物なし・全面緑、入力検証、日本語パスのPNG/JPEG、CLIのJSONと保存画像、破損・空・存在しないファイルを検証します。合成画像での成功は実際のバジル写真での精度を保証しません。

## 次に試すこと

まず緑色でない無地の背景を使い、真上から同じ距離・画角・照明で実際のバジルを数枚撮影し、確認画像の漏れと過検出を調べてください。必要に応じてHSVしきい値を調整し、手作業で塗った正解マスクと比較するのが次の段階です。その後、固定撮影による日ごとの比較、基準スケールによる投影面積の換算、AIセグメンテーションを順に検討できます。

個体識別、時系列記録、実面積換算、DB、API、カメラ取得、センサーデータ統合、成長・収穫予測は今回実装していません。
